# create-vortex-app

Le moyen le plus simple de démarrer un projet Vortex depuis n'importe quel terminal !

## Utilisation

```bash
npx create-vortex-app mon-projet
# ou
npm init vortex-app mon-projet
```

## Fonctionnalités
- Génère un projet Vortex minimal ou complet
- Support TypeScript
- Templates inclus
- Prêt pour Next.js et React

## Développement

- Le code source est dans `src/`
- Les templates sont dans `templates/`
- Compiler avec `npm run build`

## Publication

```bash
cd packages/cli
npm run build
npm publish --access public
```
